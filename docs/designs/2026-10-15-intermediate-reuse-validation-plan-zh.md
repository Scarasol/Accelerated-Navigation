# 构图中间产物分层复用验证

日期：2026-10-15。独立原型目录 `.tmp/intermediate-reuse-20261015/`。

本轮验证尚未接入生产的新方向，不将既有 facts、SectionGeometry、SharedRows、单次 build 内查表优化重复计作成果。不修改生产源码、预算、JVM、TTL，不涉及持久化、历史估计和跨 tick 偿债。

## 候选与假设

第一层只缓存不可变 PackedFacts 的四个原始标志位平面，以 16 格一行为单位惰性建立，每行打包进一个 long。第二层按当前 GeometryKey 拼装 volume/ground 行，精确形状仍调用原 volumeOpen；第三层原侵蚀、组件、边与发布规则保持原样。遇到门的输入首版退回原行生成，计入覆盖率和成本，不猜测开门语义。

缓存归实验 worker 所有，身份为 PackedFacts 对象引用，固定上限 64 个源对象，FIFO 淘汰；不以 fingerprint 相等作为身份。它缓存纯原始事实，不缓存 halo 合法性、组件号或跨代发布许可。每次组合仍从本次 BuildInput 取事实并沿原规则登记 haloUsed。缓存清空须释放源对象与行数组。复用资格不改变原 runtime 的 loadIdentity/revision/完整发布校验。

该设计不是完整 legalMask 或 prismMask 缓存。相同 GeometryKey 的重复完整 Base 构建不作为主要机会，因为生产已有 Base 缓存。局部构图是否值得使用同层需单独记账，不能将已有 LocalKernel 的惰性合法性误计为新增收益。

## 冻结与测量

1. 冻结当前生产源码、fixture 与原始工具配置，保存哈希；基线从本次快照生成。
2. 先用真实 Base 构建逐项比较 legal/prism、标签、组件元数据、边/能力/浮点位、haloUsed 与 stamps。覆盖普通地形、精确薄形状、UNKNOWN、门、流体、GROUND/VOLUME、偶数对齐、缺失与已加载 halo、事实替换、淘汰及清空。
3. JFR 自定义阶段事件记录行生成、侵蚀、组件、边、输出；原生计数记录原始 flags 解码、精确判定、缓存行建立/命中/淘汰与消费者。自动读取 GC 暂停、锁、park、IO、栈样本、分配样本、DataLoss、实际启用设置与线程。CPU 仅以批量计数作补证。
4. JMH 1.37 调用本次真实内核，独立 fork，固定 warmup/measurement，消费结果。主对照覆盖一次使用（无复用）、两种及四种不同 GeometryKey；每个操作清空缓存后建立并消费，包含创建、查询与清理。热缓存命中另列，不能替代完整操作。gc profiler 单独运行；留存用 Instrumentation 身份去重。
5. 必须取得实际消费者关系，区分人工可复用上界与实服机会。只有正确性和完整局部成本通过才做小范围服务器对照：场景就绪真实 30 秒后开始，诊断与无深度插桩性能对照单列，保留首 Path、自然到达、完整 tick、失败、图/任务数与清理。

## 停止条件与结论边界

正确性不一致先修正并保留失败记录；若结构性语义冲突则停止。无复用成本或精确例外抵消收益、需要过多消费者才回本、实际消费者关系不足、额外留存无法接受，均不得宣布生产可用，也不扩展并发大矩阵。若成本门不通过，直接结束此候选，报告具体数据和是否值得更窄设计；不自动实施第二研究方向。

DeepSeek 继续使用 WSL 原生 dsh 无头，provider=deepseek、model=deepseek-v4.1-flash；每包自足，UTF-8 不超过 6500 字节，本地截止 900 秒，保存请求、原答复和退出信息。上游持续 504 时记录未取得共识，不冒称批准。

## 首批执行中的归因补充

首批 rowLifecycle 对照保持原参数和全部结果。`exact-halo-0` 为合成压力输入，26 个 halo 引用同一个不可变 facts，是复用上界，不代表实服不同 section 的对象分布；`flat` 是无 halo 普通输入。两者不用于估计实服命中率。

为区分批量行派生的单次构建收益与跨体型留存收益，完整 Base 对照额外增加 `rebuildEachBody` 控制：候选代码相同，但每种体型前清空缓存。该控制在完整 Base 性能运行前确定，不能以批量派生相对基线的全部收益冒充跨消费者共享收益。每组仍为 1/2/4 个不同 GeometryKey；门输入明确回退。若通用单消费者成本回退且缺少实服复用证据，停止生产推进，即使人工四消费者有收益也不能据此接入。
