# 详细搜索节点缓存命中精简隔离方案

日期：2026-10-23。用户授权研究一次搜索内缓存，与1017成案后验证。
证据目录：`.tmp/detail-cache-hit-20261023-v1/`。

## 1. 唯一改动

从冻结NTL复制NCH，保留邻域安全摘要、节点计时修正和普通最多四连接。
只增加一个NodeEvaluator Mixin及清单项：

1. 按原`Node.createHash(x,y,z)`查询原`nodes`表。
2. 返回值不等于该表的`defaultReturnValue()`时直接返回。
3. 其余情况仍走原`computeIfAbsent(key, k -> new Node(x,y,z))`。

不新建缓存，不跨查询或实体共享节点，不修改prepare清表、原hash碰撞行为、
搜索限额、目标、启发式、世界读取、worker和派发。
通行类型表、碰撞表、EnumSet和路径重建均不混入本候选。
基类改动也会影响继承该节点方法的非地面evaluator，不能只声称影响地面。

选择保留原miss调用，而非计算后put，是为了保留实际fastutil8.5.9的
存在判断、计算和插入行为。命中避免先求值捕获factory；miss多一次查表，
正常命中多一次默认返回值读取，是否净收益由实测决定。
JIT可能已消除原factory对象，不能从源码推算分配节省。

不能使用`node != null`作为唯一条件：protected表允许子类设置非null默认值；
已存null或已存默认对象也必须保持原有返回语义。
当前A+会让这些情况重新经过原computeIfAbsent，避免增加containsKey。

## 2. 实现与兼容边界

使用一个`@Overwrite getNode(int,int,int)`及`@Shadow @Final nodes`。
Inject HEAD会引入回调对象；包住computeIfAbsent时lambda已经求值；
不加另一层搜索后端或逐节点资格检查来替代这个小方法。
保留可见性、虚调用和BlockPos委托。

覆盖核心方法存在其它Mixin冲突风险。本轮只验证现有实际发行环境，
不把隔离成功扩称整合包通用兼容或生产通过。
实际异常/OOM不注入；miss异常与插入时序只核对源码和实际库字节码，
不能记录为已完成异常测试。

## 4. 最小验证

独立Forge/Mixin正确性控制比较原算法参考：
重复/不同键、原hash碰撞、prepare后新节点、两个evaluator、BlockPos委托、
非null默认值未命中、已存null及已存默认对象。
地面和确实继承基类方法的飞行/游泳各一条真实PathFinder差分，
比较完整路径坐标、目标、类型、canReach/partial。
这些控制不进入正式性能JAR，不另建门/台阶/体型性能矩阵。

字节码确认primitive get/defaultReturnValue和返回分支位于invokedynamic之前，
miss保持原库同重载，新增方法没有CallbackInfo/Operation；
实际Mixin转换和prepare清理保持。

性能仅新增NCH一个JVM，沿用原接口、工具和计量：
35ms均值、sigma5ms、seed20261021，64/128/256实体各8/28格，共六场896请求。
复用NTL首轮和原样复跑，以及NT/NS/U/P/N有效历史，不重跑旧版本。
全量报告搜索wall/CPU/分配、首Path、完成与到达、恢复、
自然窗成本和tick峰值，不事后删换线或尖峰来认定因果。
不追加15/25、304、同JVM复跑或新配对。

语义或字节码不等价先修或停；miss额外成本抵销命中节省、
主指标没有值得保留的净收益，或正确性/恢复/tick负项抵销收益时停止，
不调启发式、不扩矩阵救结果。
NTL相对NT的高分配尚无具体分配点证据，不能由本候选宣布关闭根因。
200ms仍为整个项目的到达目标，不作为本分支独立门。
