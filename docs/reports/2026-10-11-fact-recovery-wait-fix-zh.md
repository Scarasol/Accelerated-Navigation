## 编译和原始失败

原计划执行 `gradlew.bat --offline --no-daemon --console=plain -Dorg.gradle.jvmargs=-Xmx1g compileJava compileTestJava`。Gradle 在编译前退出1，原因是 `java.io.IOException: Unable to establish loopback connection`。因此没有宣称 Gradle 构建通过，也没有修改 Gradle 配置绕过该错误。

使用本机 Java 17.0.18+8 和现有项目依赖，以 UTF-8、Java17、关闭注解处理的方式直接编译全部22个生产源码单元及2个测试单元，均退出0；产物已更新到 IDEA 实际使用的 `build/classes/java/main`、`build/classes/java/test`。本轮没有改 Mixin，保留既有资源和引用映射。此结果支持 Java 源码编译及本次反馈，不替代 Gradle 打包。

初次反馈因宿主在注册表初始化前访问维度常量退出1，已把该初始化移到原生 Bootstrap 之后。修复版首次反馈又发现临时输入使用了生产只作非持久化发布的隐式全空气快捷表示；改用实际扫描/序列化路径的完整事实后，对照成立。两个失败及首个 Gradle 错误均原样保留，没有改判成通过；没有因此修改生产几何或格式。
