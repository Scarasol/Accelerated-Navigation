# S1 原样复跑与候选封存

日期：2026-10-20。用户原授权：“准许再跑一轮，看看结果是否稳定，如果稳定就放弃”。

## 决定

**放弃 S1 阶段调度合并候选，保留隔离代码和证据，不接入生产。**

本次原样复跑再次出现 28 格整场 CPU 高于同一历史生产基线，
两条秒级不利到达尾部也落在原来的同两条路线。
实际到达中位仅改善约 5 ms，原首 Path 收益未保住，没有实现接近 300 ms 的改善。
这些观察支持停止投入这个候选的工程判断。

“再次出现”指不利方向和两条尾部路线重复，不指 CPU 增幅数值稳定、
统计显著或已证明由本次代码直接造成。
首轮到复跑的 CPU 幅度明显变化，不能声称已经证明“数值稳定”或严格满足稳定性条件。
停止的决定基于收益不足及重复的不利现象，不将该判断冒称为已经证实用户条件。
根因仍未定位；不再据此扩跑或修改 S1。
放弃范围只限 S1，不是放弃生产 S9L 或相对原生到达增量 200 ms 的长期目标。

- 直接复用原 `net-build-v4`，不重编译、不改源码。
  原制品 SHA256：
  `565fe1ec90d49ff52fc181ae2e77242fdec89fe923f0f0fd7a010f4dcbec08c8`。
- 原 agent、probe、helper、JDK、JVM 参数、世界模板、场景、速度 II、
  30 秒就绪等待、DEBUG/NoTrace 和计量接口全部对齐。
  仅输出目录及运行时间等必要运行身份不同。
- 启动前核验 2268 个受保护输入。S9L、10 月 19 日历史调度 B、原生 N0
  和 S1 首轮数据直接复用，零基线重跑。
- 新一轮 128/128 实际到达、128/128 成功；无其他 Java 并行干扰。
  JVM 正常退出，关服 records、active、pending 均为零。
- 两场分别仍为 99/142 次真实搜索；与首轮和 S9L 的逐实体搜索次数、
  null/partial/reachable 数量及最大返回节点数相同，不证明内部逐节点执行相同。

首轮与复跑只作两次独立记录，不合并成“多次平均稳定收益”。
分位数沿用历史 nearest-rank，各实体自己的 submitStartNanos 为主起点；
所有 64 条唯一完整路线键逐项对齐。
