# GPU图内并行隔离优化验证

日期：2026-10-27。落实[上一轮方案](../designs/2026-10-27-gpu-intra-graph-parallelization-plan-zh.md)，
承接[依赖推进候选](2026-10-27-gpu-dependency-pipeline-and-discrete-support-zh.md)。
目标仍是[完整宏观后端迁移](../designs/2026-10-27-gpu-macro-backend-cpu-architecture-alignment-zh.md)，
本轮完成其中构图内部计算优化，尚未完成生产后端接线。

## 1. 结果

新候选完整流程中位数为 **7.5179/49.4182ms**（单体型/混合体型），
比上一依赖推进版下降 **83.14%/69.70%**，比CPU生产执行器历史参考下降
**54.35%/83.66%**。本次图内优化有效，保留候选。

但没有全面超过历史最优批量GPU：混合体型仍慢6.91%，
热查询整套工作负载和显存容量也有负项。暂不建立生产准入。
生产代码、历史CPU/GPU和游戏/原生测试数据均未改动。

## 2. 实现

隔离源码：`.tmp/gpu-intra-graph-parallel-isolated-20261027-v1/`。
从前版第三份隔离实现继承原生事件依赖、同就绪最多32图有限任务组、
生产TopologyTaskExecutor的优先级与异步提交方式。
不增加凑批计时器、主线程预算或逐候选CPU结果往返。

- **组件**：含门时不再整图交给lane0串行BFS。普通同高一格连接采用原规则的
  精确流式判定，64项工作组合并并查集；原子读取/合并使用一致协议。
  根先存到独立标签暂存，再用分块前缀编号，保留最小格递增的组件ID。
  坐标界限和最小anchor用32位归约，不再串行扫描整图更新每个元数据。
- **连接边/边界**：按格或入口并行判断候选，接受位和待检查位固定存放，
  非空待检查字紧凑登记。共享精确行按目标格升序重建，不再每lane插入排序72项。
  边界按入口前缀确定记录区间，完整保持原入口、方向、距离及落差的记录顺序。
  能力OR、非负代价min及原双精度表达式保持。
- **完整几何**：困难项仍执行原矩形收集、坐标轴和精确安排图检查，
  frontier BFS由组内64项分担，CAS防止重复入队。
  共32个独占暂存槽，跨命令复用通过前一持有事件串联，不通过自旋等待producer。
  预处理、最终输出和无关查询仍各自按依赖推进；不宣称所有内核都同时计算。
- **父图**：出度统计和CSR稳定填充按节点并行；补回CPU已有的线性稳定成员索引，
  凝缩不再逐分量扫描全部节点。元数据先归约anchor，再同步后OR出口。
  原反向边顺序、SCC遍历/编号、首次目标顺序及unsigned witness同分规则保持。
  SCC、反向CSR、最多1024节点的CSR前缀和及部分凝缩尾部仍串行，未冒称全并行。

原串行内核仅在计时外建立固定元数据及参考初态，正式fresh构图全部走新入口。
查询内核和查询分组策略不变。旧逐图几何暂存仍由该初始化框架保留，
没有在本轮删除它们；其容量计入下述显存负项。

## 4. 正确性

默认一条乱序队列、强制五条有序队列、启用共享精确行三项控制，
各自核对原有单体型和混合体型，全部通过：

- 逐格合法位和组件标签、组件元数据、能力/成本、邻居位图；
- 有向边界band及聚合边，另逐项对比旧GPU原始记录的完整写出顺序；
- 父图展开/凝缩CSR、SCC编号、元数据及witness；
- 请求路径、成本和同分结果；
- 共享行分别101218/394845条邻接与生产LocalKernel一致。

默认控制中完整几何分别处理437/820项，启用共享行时903/1646项；
暂存跨命令复用按原生事件依赖核对，无重叠持有；
最多访问62个安排图节点，未越过67600节点/队列容量。
所有控制都看到搜索在无关构图结束前启动，执行器任务失败为0。
这不等于真实动态世界的缓存/取消/更新生命周期已经接线。

原五组320项几何查询全部匹配生产BoundaryGeometry，
GPU实际182项直接确定、138项完整协作检查，困难夹具仍覆盖完整检查。
与上轮主机证明181/139的分流数量不同，仅mixed的总索引251：
`(10,5,14), west, distance=3, dy=-4`；
主机证明为UNKNOWN，GPU由端点条件判不通，生产最终也不通。
分流不同没有形成最终可达性差异，不把主机比例硬套为GPU命中率。

首次几何控制曾因错误地要求分流数必须等于181/139而失败；
当时320项最终bool已全部匹配生产。纠正的是控制断言，未修改GPU计算内核。
同320项的计时外分流诊断及执行记录保留，不重跑性能矩阵。

本轮满足“图内并行整体候选已实现并隔离验证”，
值得作为后续实现基础；尚不满足生产验收或完整宏观GPU后端迁移完成。
