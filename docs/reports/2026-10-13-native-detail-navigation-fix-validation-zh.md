## 修改及原因

| 位置 | 修改 | 对现行设计的作用 |
| --- | --- | --- |
| `GroundAbilityGuard`、`SegmentedNavigationService` | 删除资格扫描、qualifiedWindow、retainAbilityProof、requalifyWindow 和相关字段；删除 legal 候选碰撞/支撑预筛 | 详细可行性由真实原版 PathFinder/NodeEvaluator 决定 |
| 宏观完成与窗口准备 | 当前候选直接排队进入真实分段搜索；不再预先遍历整条走廊批准资格 | 宏观只提供候选与当前性 |
| 地面执行恢复 | 删除因资格、语义 proof、无宏观候选而切换 nativeWhole 的分支；候选不足返回 UNAVAILABLE | 不绕开分段预算目标，也不把宏观不足冒称实体真实无路 |
| 实际原版读取输入 | NativeQueryProof 仅捕获实际 PathNavigationRegion 的区块身份/版本；删除邻域任意集合捕获；旧输入失效暂停节点并在 END 重新调用真实当前段搜索 | 版本保护只负责旧结果当前性，不批准新输入可行性 |
| 纯查询 | 未采用的已适配异步查询使用原始目标集合、accuracy/range/offset/multiplier 和能力快照调用真实原版；单列 nativeDecisionCalls | 不伪造 canReach；查询不移动实体、不替换活动路径 |
| READY 采用 | 真实查询选中的多目标结果被采用后固定到该目标；重规划保持绑定 | 不把真实选中的远目标换回较近但原生不可达的目标 |
| 已采用 Path 复用 | 重复 moveTo 同一活动请求只更新速度，保留真实节点、索引、状态和任务身份 | 避免把重复采用当作首次 READY 采用而重启任务 |
| 等待中纯查询的采用 | searchNative 真正派发前复核 adopted；已采用地面请求转入宏观分段，只有原先未取得分段资格的类型进入兼容执行 | 防止空中等待的纯查询在落地后发布整条查询 Path，并沿错误的分段状态结束 |
| partial 与完成 | 发布真实 partial 节点供原版执行；canReach 保留原生结果；末段 partial 不延迟最后节点至虚假到达，正常耗尽为 EXHAUSTED；成功要求最后原生可达和实际最终 accuracy | 保留部分路径语义，不误报全程成功 |
| 预览 | partial 不被直接当作阶段完成；末段 partial 预览为 EXHAUSTED，预览继续明确不等于实体执行资格 | 查询节点预览不放大原生结果 |
| 诊断 | 记录宏观候选、实际窗口输入及真实详细结果；区分分段、纯查询和整条兼容执行次数 | 路线失败可按真实后端与恢复结果归因 |

宏观拓扑、几何事实、存储格式、压缩、共享调度器和恢复上限未修改。4ms 仍是共享软预算，原版调用仍是原子调用。实际任务取消、控制代次、TTL、能力保存恢复、prepare/done、关闭和原生物理完成检查保留。完成检查发生在真实节点执行之后，不是搜索前资格判断。

## 覆盖和结论边界

实际发行包有 295 项 Mixin/映射检查通过。新字节码清单重新枚举当前 Forge 的 10 个 Navigation 子类，并列出 nativeWhole 的实际调用者；五类导航的入口、参数、局部安全和取消在发行夹具验证。未知第三方 override、未适配同步消费者、特殊导航完整路线和长期服务器负载仍是边界，不能扩大为全实体兼容或性能通过。

大 range 纯查询仍有输入保留边界：NativeQueryProof 最多保留 256 个区域区块身份，超过 256 时返回 null，READY 当前性检查会拒绝采用。此范围没有本轮发行资格证据，没有以缩小 API 参数或放宽上限制造通过。调度器另有 13 项确定性预算控制通过，但独立读者没有对实际负载下 samples 的单次超支、跨 tick 负债、跨维度公平性作性能断言。运行约 731 秒、最多四个并发 Goal，只支持本轮集成资格。

前序运行只作版本历史保留。最终包的路线、反例、资源和发行身份结论来自 `server-deferred-final`，不能混用 `server-accepted` 或更早版本的计数。集成验证不代表复杂地形的普遍可达性或长期服务器性能通过。
