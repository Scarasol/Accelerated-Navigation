## 西侧：关闭的门被连接穿过

唯一两个候选：

| 源格 → 目标格 | 实际方块 |
| --- | --- |
| `(-17,72,-217) → (-16,73,-217)` | 关闭的云杉门，右铰链，下半部在源格，上半部在 `(-17,73,-217)` |
| `(-17,72,-216) → (-16,73,-216)` | 关闭的云杉门，左铰链，下半部在源格，上半部在 `(-17,73,-216)` |

两扇门朝西，保存碰撞盒的X范围均为 `[-16.1875,-16]`，竖向为 `y=72..74`。默认身体宽0.6格、高1.95格，站在源格中心时身体的东边为 `x≈-16.2`，门恰好在静态身体之外。因此“能站在这个格子中心”成立，**“能从这里向东穿过门”不成立**。

这不是只依据斜线撞到门作判断：两个候选允许的一格上台阶，脚底高度处于72至73之间；在交界面，上半扇门对这个高度范围内的身体始终构成碰撞。先抬高再平移也无法排除门。当前能力没有开门动作；此结论针对关闭状态，不把开门后的通行判为失败。

实际调用链是 `TopologyWorkerRuntime.buildBaseBoundaryLinks` → `SuperClusterTopology.boundaryLinks` → `addBoundaryMask`。末端只检查目标格组件标签，未消费碰撞盒或验证两格间通行。`SectionGeometry.occupied` 检查格心静态占用，不足以保证这条跨区连接有效。这是**通行连接没有消费已采集几何**，不是采集不到门、搜索上限过小或需要对云杉门设特判。

用生产 `boundaryLinks` 独立核对，两版图均生成上述两个候选。因此错误连接早已存在；新图路线变化可能使旧缺陷更容易被走廊选中，不能归因成此次新增了开放墙格。

源码位置：[格心占用](../../src/main/java/com/scarasol/acceleratednavigation/topology/SectionGeometry.java#L139)、[边界枚举](../../src/main/java/com/scarasol/acceleratednavigation/topology/SuperClusterTopology.java#L281)、[目标标签检查](../../src/main/java/com/scarasol/acceleratednavigation/topology/SuperClusterTopology.java#L325)、[生产调用](../../src/main/java/com/scarasol/acceleratednavigation/topology/TopologyWorkerRuntime.java#L1634)。

## 东侧：通口和锚点直线位于不同位置

重放路线这条连接的全部候选是：

- `(96,84,-265) → (95,84,-265)`
- `(96,84,-264) → (95,84,-264)`

两端均为空气，身体从一端平移到另一端不与保存碰撞盒相交。源侧组件150个格、目标侧165个格；分别检查所有同高相邻格的身体扫掠后，均保持一个连通区域，没有被门或玻璃板截断。

另枚举此区段对的全部默认能力连接，共4个候选：上述两个，以及同位置 `y=90` 的两个；四个跨界扫掠均无碰撞。完整生产方法对照核实了重放路线使用的两个。

从显示源锚点 `(102,84,-271)` 到显示目标锚点 `(81,84,-271)`，保存了一条33步的逐格通路，每一步均用两区段全部保存碰撞盒重新检查，无碰撞。转折如下：

```text
(102,84,-271)
→ (102,84,-270) → (98,84,-270)
→ (98,84,-266) → (97,84,-266)
→ (97,84,-265) → (84,84,-265)
→ (84,84,-267) → (81,84,-267)
→ (81,84,-271)
```

其中经过的交界是 `(96,84,-265) → (95,84,-265)`，即需要沿Z方向偏移6格再跨界。该通路是离线几何见证，未接入详细寻路，不宣称已经认证完整实体运动。

而 `NavigationCommand.sampleCorridor` 直接连接两个组件代表锚点；该直线保持 `z=-270.5`，粒子高度为84.5，确实会穿过：

- `(95,84,-271)` 及其上方的灰色玻璃板；
- `x=96..101,z=-271` 的灰色陶瓦墙及蓝色玻璃板；
- `(86,84,-271)` 及其上方的铁栏杆。

这是对具体墙体、具体显示直线和具体绕行通口的核对，不是用“宏观线可能穿墙”代替诊断。但目标游戏日志没有保存端点组件或边界候选，离线重放也不能冒充当时的逐条路径记录。因此这部分的准确结论是：**重放连接存在无碰撞通路，显示直线有穿墙；当时游戏是否另用了错误连接，证据不足。**
