## 复测范围

- 基线：共享投影事件排序原型；
- 候选：基线加节点支撑高度/Box 位图共享；
- 三个独立 JVM，首轮顺序分别为基线优先、候选优先、基线优先；
- 每个 JVM 两个变体、三个代表，每变体首次1次、预热8次、测量9次，共108次构图；
- 总计324次构图、162次测量；
- Java 17.0.18、G1、Xms128m、Xmx1g；
- 不使用 JFR、不显式 GC、不扣除 GC、不挑选后段；
- 每次仍是一个16×16×16格区段的完整构图。

历史资格和图对照未重复运行，因源码、夹具、输入和观测边界未变；每个 JVM 的每个测量轮仍执行基线/候选图等价对照，共54次。
