## 基线和范围

用户授权先检查生产区，存在未提交生产代码则保存到 `1.20.1`，随后执行生产接入。开始时生产代码干净，已有两个本地提交尚未推送；已将 `fafdf8b` 和 `c7fa006` 推送至远端 `1.20.1`。

冻结生产基线为 `c7fa006`，包含当前 Boundary 优化。本次保留它的源码和行为；两臂共同含此优化，本轮不能替它关闭此前独立验收中仍为 INCONCLUSIVE 的性能门。

生产仅改动：

- `BaseClusterTopology`：将逐格原始 flags 行构造替换为已验证的 doorpacked 生成；缓存归现有 `BuildScratch`，不同 runtime 独立，由现有串行 BUILD/PREWARM permit 保护。无 ThreadLocal、模式切换、晋升缓存、实验计数或 JFR 生产事件。
- `TopologyWorkerRuntime.awaitStopped`：只有两个 worker 全部 join 成功才清空行缓存。超时不清仍可能在用的缓存，重复等待成功后清空。

每个源最多惰性生成 256 行，每行四个 16bit 平面。弱身份键、FIFO 64 源，value 和 FIFO 均不强持有源。只复用不可变体型无关事实；门、流体、精确碰撞及 halo 依赖仍在每次构建按原方法处理。中心 y0 支撑推导、缺失当前 halo 时可开门逻辑对已加载下方 halo 的读取副作用保持。

## 当前代码验收

从未改的冻结基线和当前生产源码分别 javac，独立 JVM 的 2,380 个完整图与 volumeRows、groundRows、legalMask、prismMask、haloUsed 摘要全部一致，摘要 SHA256：

`8841691d1e7da124e28c2a062145e481a751c4a5734e0f62d058960229e802b8`

跨 JVM 仅排除含 enum identity 的 `signatureHex`。signature 函数与基线逐字相同，所有其余输入均在对照中；签名用于同 JVM 的 Base/Boundary/Parent 身份检查和诊断导出。生产持久化存基本事实，不存本次派生行缓存或图签名；不宣称跨 JVM 签名稳定。

另有 20,090 个缓存断言：64 基向量、10,000 随机行及再次命中、16 flags/allAir、80 个强可达源淘汰至 64、相同内容不同身份、弱源 GC、清空和所有权；双 worker 40 对独立图检查通过。64 源缓存强可达为 142,280B，低于 8MiB 门。

实际 runtime/执行器另测 8 轮在途构建与停止：1ms 等待超时不清缓存，任务放行、worker join 成功后 map/order 为空，重复 stop 正常。另 64 个 BUILD 实测峰值并发 1。

`testClasses`、现有 CoreContracts（含 Reverse 3 项）、额外 boundary-recovery 9 项、door 契约、既有 SharedRuntimeProbe 的 1,296 项检查及 jarJar/reobf 均通过。各命令包含交叉覆盖，不把这些计数相加冒充独立测试数。

## 诊断与正式性能

单独诊断服务器运行实际候选发行包，额外诊断 jar/JFR 均不进入净矩阵。整台生命周期记录 194,944 次行查询、55,936 次命中（28.69%）、139,008 次行 miss、550 次源 miss，源数最高 64，非法索引为 0。该口径包含启动，不作为纯冷阶段命中率或净性能结果。JFR DataLoss 为 0，真实请求窗口有 64 个 deriveLegalAnchors 事件；此事件包含原始行、侵蚀及 sealed-cell 过滤，不能冒充纯 row fill。

正式净矩阵：complex/same 各四对独立 JVM，顺序 AB/BA/AB/BA；每台新世界，场景实际 ready 后至少 30 秒才提交 16 请求。29 秒另一 tick 核验目标 Base/Super 冷态。JFR、逐格计数、capture、trace、编译日志关闭，双方共同完整 tick 与 tick END 首 Path/终态观察器保留。

统计和工程门沿用原已审方案。首 Path 每 JVM 的 16 实体排序索引 7，再四 JVM 平均；配对差单侧 90% t 上界使用 df=3。tick 为提交至最后自然终态相交的完整 tick；GC 同一窗口，日志时间分辨率 1ms。样本少且首 Path 观察约一 tick 量化，不能声称普适显著提速。
