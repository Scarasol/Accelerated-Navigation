## 实现与1017共识

原生循环先覆盖邻点walkedDistance，再判断累计长度及新g是否可接受。
拒绝候选时，旧前驱/g可能保持而累计长度被覆盖。
修复只将候选长度延迟到接受前驱时写回：

```java
float candidateWalked = parent.walkedDistance + distance;
float newG = parent.g + distance + next.costMalus;
if (candidateWalked < range && (!next.inOpenSet() || newG < next.g)) {
    next.walkedDistance = candidateWalked;
    next.cameFrom = parent;
    next.g = newG;
    // 原有启发式及heap处理保持
}
```

只作用项目raw搜索，普通原生查询继续原行为；不用含malus的g代替几何长度。
新增NativeWalkedDistanceMixin及清单项，采用三处精确字段Redirect，
每查询HEAD捕获一次raw标志。没有复制整个A*，没有每邻点CallbackInfo、
Operation、LocalRef或新集合；三次helper和条件判断仍有成本。
range公式/上限、region、访问上限、目标、权重、闭集、heap、宏观、worker、
调度及其它缓存都保持。修复错误裁剪可能允许更多合法展开，不承诺所有输入成本下降。

方法包5228字节完整返回，与1017形成三处Redirect的共识。
其关于allow=1是“放宽”的措辞已纠正：实际是注入上限，保留精确上下限。
代码首审7100字节因推理输出耗尽、无正文失败，原响应保留；第二包6102字节完整返回
**ACCEPT，无MUST_FIX**，只允许执行原定隔离性能验证，不是生产批准。

实际转换字节码核对三个字段替换及HEAD各命中一次，父walked读取保留。
原276包条目保持；既有差异仅manifest/refmap/Mixin清单，新增一个Mixin类。
探针44条目相同，附带refmap仅新增本Mixin映射；没有修改探针逻辑。
