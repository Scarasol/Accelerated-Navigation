## 指标口径

以 JVM 为重复单位，不把 tick 或实体当作独立样本。每台纳入提交时刻至最后自然终态之间所有相交且正常完成的完整 tick：`end >= submitted && start <= lastTerminal`。不删除首搜或慢 tick；窗口外的 29 秒冷检查不纳入。

每台有 621–623 个合格 tick。p99 取排序索引 `floor((N-1)*.99)`，本轮均为第 8 大值。先算每台 p99，再按 JVM 统计，未混池所有 tick。这里是整段请求窗口的服务器 tick 指标，不是构图或单次寻路耗时。

首 Path p50 沿用 16 实体排序索引 7；GC 使用同请求窗口，日志时间分辨率为 1ms。没有用 GC 或同步调用耗时从 tick 中扣除后重新验收。
